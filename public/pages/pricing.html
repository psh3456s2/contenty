자주 묻는 질문

결제는 어떻게 이루어지나요?
Stripe를 통한 안전한 카드 결제가 이루어지며, 매월 자동으로 갱신됩니다.
언제든지 취소할 수 있나요?
네, 언제든지 구독을 취소할 수 있습니다. 취소 후에는 현재 결제 기간이 끝날 때까지 사용 가능하며, 이후 Free 플랜으로 자동 전환됩니다.
하루 생성 횟수는 언제 초기화되나요?
매일 자정(KST 기준)에 초기화됩니다.
API 키를 따로 준비해야 하나요?
아니요! 별도의 API 키 준비 없이 로그인만 하면 바로 콘텐츠를 생성할 수 있습니다. 요금제에 따라 하루 생성 횟수가 제공됩니다.
